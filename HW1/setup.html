How to setup a VM

  1. Ensure the host machine has enough RAM and other resources to run all your VMs.
  2. Ensure virtualization is enabled on the hosts systems BIOS.
  3. Download the OS you will want to run on your VM.
  4. Install a hypervisor such as Oracle VM VirtualBox, Microsoft Hyper-V, VMware, or another hypervisor you prefer.
  5. Using your hypervisor create and configure a new VM, provide the ISO of the OS you downloaded and provide the storage space where it will be stored. Most hypervisors will have setup guides for their specific setup process.
  6. Start your VM and you will now have an isolated envirnment to use!
